# カレンダーメモ (Calendar Memo)

Google カレンダーと連携して、予定やタスク（チェックリスト）を直感的に管理できる軽量な Web アプリケーションです。
バックエンドサーバーを必要とせず、HTML/JavaScript 単体で動作します。

## 主な機能

* Google カレンダー同期: Google Calendar API を使用して、自身のカレンダー（primaryまたは指定したカレンダー）からイベントを取得・更新します。

* ステータス管理: カレンダーのイベントカラーを利用して、予定のステータス（未完了 / 進行中 / 完了 / 中止）を変更・管理できます。

* インタラクティブなタスクリスト: メモ・詳細に - [ ] タスク と記述すると、画面上で操作可能なチェックボックスに自動変換されます。チェックを入れると Google カレンダー側にも即座に保存されます。

* 表示フィルター: 「完了」や「中止」の予定を表示/非表示に切り替え可能です。

* 安全な設定保存: OAuth Client ID などの設定情報は Web Crypto API（AES-GCM）により暗号化されてブラウザの localStorage に保存されます。

## セットアップ手順

本アプリを使用するには、Google Cloud Console で OAuth 2.0 Client ID を発行する必要があります。

### 1. Google Cloud Console での設定

1. Google Cloud Console (https://console.cloud.google.com/) にアクセスし、新しいプロジェクトを作成（または既存のプロジェクトを選択）します。

2. 「APIとサービス」 > 「ライブラリ」 に移動し、「Google Calendar API」 を検索して有効化します。

3. 「APIとサービス」 > 「OAuth 同意画面」 に移動し、必要事項を入力して保存します。

   * テストモードの場合は、テストユーザーに自身の Google アカウントを追加してください。

4. 「APIとサービス」 > 「認証情報」 に移動し、「認証情報を作成」 > 「OAuth クライアント ID」 を選択します。

   * アプリケーションの種類: ウェブ アプリケーション

   * 承認済みの JavaScript 生成元: アプリを配信・実行するURL（例: http://localhost:8000 や https://your-domain.com 、ローカルファイルから開く場合は実行環境に合わせて設定）

5. 生成された クライアント ID（xxxx.apps.googleusercontent.com の形式）をコピーします。

## 使い方

1. index.html をブラウザで開きます。

2. 初回起動時は設定画面が開きます（開かない場合は右上の 「設定」 ボタンをクリック）。

3. コピーした OAuth 2.0 Client ID を入力し、「保存」 をクリックします。

4. 「Googleでログイン」 ボタンをクリックし、Google アカウントで認証を行います。

5. ログインが成功すると、Google カレンダーの予定がカード形式で表示されます。

## 便利な使い方・テクニック

### 1. メモ内にチェックリストを作る

予定を作成または編集する際、「詳細 / メモ」欄に以下のように記述します：

```
- [ ] 持ち物の準備
- [x] チケットの購入
```

画面上ではチェックボックスとして表示され、画面上でチェックを切り替えると自動的に Google カレンダー側のテキストも - [x] に更新されます。

### 2. ステータスの切り替え

各カードの右側にあるドロップダウンメニューからステータスを変更できます。
ステータス変更時、Google カレンダー上ではイベントの色（Color ID）が変更されます。

* 未完了: 標準色
* 進行中: 青色 (Color 7)
* 完了: 灰色 (Color 8)
* 中止: 赤色 (Color 4)

## 技術構成

* フロントエンド: HTML5, CSS3, Vanilla JavaScript (ES6+)
* 認証: Google Identity Services (GSI) SDK
* API: Google Calendar API v3
* 暗号化: Web Crypto API (SubtleCrypto / AES-GCM)
